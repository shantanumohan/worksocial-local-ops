# `@worksocial/console`

Minimal console (R1-02 → R1-04):

- `/login` — real local session login (not cosmetic)
- `/authority` — operating mode, stop switch, honest connected/authorized/verified labels
- `/mapping` — production bindings, adapter status (NOT_WIRED/FIXTURE), write-path evidence
- `/roles` — A01–A30 status, last-run evidence, fixture evaluate-all

Full React route map (v5 25 screens) is out of scope for this slice. No live providers.
