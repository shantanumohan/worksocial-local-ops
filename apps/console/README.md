# `@worksocial/console`

Minimal console:

- `/login` — real local session login (not cosmetic)
- `/authority` — operating mode, stop switch, honest connected/authorized/verified labels
- `/mapping` — production bindings, adapter status (NOT_WIRED/FIXTURE), write-path evidence
- `/roles` — A01–A30 status, last-run evidence, fixture evaluate-all
- `/monitoring` — HTTP/DOM probes and form-to-CRM canaries
- `/knowledge` — fact registry + demand/trend/FAQ/rank signals with honest support labels
- `/learning` — multi-model registry, last training metrics, proposals awaiting review

Full React route map (v5 25 screens) is out of scope for this slice. No live providers. Learning is proposals-only (no authority expansion). Model claims are never facts.
