# @worksocial/ml

Local multi-model open-source learning layer for verified SUCCESS/FAILURE outcomes.

**Not production-activated.** Does not mint credentials, call the action gateway, or expand grants/spend/CRM/publish authority.

## What is real

- **≥2 pinned OSS algorithm models** in the registry (Bernoulli NB + L2 logistic risk/ranker; sklearn-compatible algorithms, BSD-3-Clause reference).
- Feature extraction from durable write-path and role-run outcome ledgers.
- Offline train/predict in CI via **fixture baseline weights** (no network weight download required).
- Versioned **proposals only** (playbook / ranking / risk) awaiting review.

## What is stub / not claimed

- No Hugging Face / ONNX weight download pipeline in this slice.
- No production-canary-verified learning; offline metrics only.
- Probe/CRM canary labels may be stubbed until R1-05.
- Proposals never auto-apply authority or spend changes.
